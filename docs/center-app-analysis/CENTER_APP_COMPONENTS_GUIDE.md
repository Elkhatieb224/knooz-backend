# دليل المكونات المشتركة — Center App

## 1. هيكل الواجهة العام
| المكون | الاستخدام |
|---|---|
| AppBar / Top Bar | عنوان الشاشة + إشعارات + أحياناً صورة المركز |
| Bottom Navigation (4 تبويبات) | الرئيسية، العمليات، التقارير، المزيد |
| KPI Cards | أرقام سريعة على Dashboard |
| Request/Operation Card | بطاقة طلب وارد أو عملية جارية |
| Primary CTA Button | قبول، بدء، تأكيد، إنهاء |
| Secondary / Outline Button | رفض، إلغاء |
| FAB / Add (+) | بدء عملية جديدة |
| Bottom Sheet / Menu | المزيد: عملاء، تقارير مالية، شكاوى، إعدادات |
| Scanner Overlay | إطار مسح QR/NFC |
| Text Fields | لوحة مركبة، بحث، كلمة مرور |
| Status Chip/Badge | حالة العملية/الطلب |
| Empty State | رسوم/نص عند عدم وجود بيانات |
| Loading Indicator | أثناء جلب API أو المسح |

## 2. بطاقة الطلب الوارد (Incoming Request)
عناصر نموذجية من التصميم:
- اسم العميل / المركبة
- الخدمة المطلوبة والوقت
- أزرار: قبول، رفض، بدء الخدمة

## 3. بطاقة العملية
- رقم/معرف العملية
- حالة (جديدة، جارية، مكتملة، ملغاة)
- الخدمات المختارة
- المبلغ
- إجراءات حسب الحالة

## 4. شاشات الماسح
- كاميرا / منطقة NFC
- تلميح نصي للمستخدم
- نتيجة نجاح/فشل
- الانتقال لتفاصيل العملية عند النجاح

## 5. نماذج
| النموذج | الحقول |
|---|---|
| Login | معرف + كلمة مرور |
| Manual Plate | رقم اللوحة (+ اختيار الدولة/الحروف إن وُجد) |
| Identity/Password | كلمة مرور خدمة مركبة شركة |
| Reject reason (مستحسن) | سبب الرفض |
| Complaint | موضوع + وصف + مرفقات اختيارية |
| Settings | تفضيلات إشعار / لغة |

## 6. Design Tokens (للتوثيق — تُستخرج بدقة من Figma عند التنفيذ)
- ألوان العلامة (أخضر/داكن حسب ملف كنوز — لا تفرض ثيم بنفسجي افتراضي)
- خطوط عربية واضحة + دعم إنجليزي
- RTL افتراضي للعربية
- مسافات Cards/Lists متسقة مع Bottom Nav

## 7. حالات المكوّن
كل قائمة/بطاقة يجب أن تدعم: loading skeleton، empty، error retry، content.

## 8. ما لا يُنقل من User App
لا تستخدم مكونات حجوزات العميل أو محفظة العميل أو خريطة المراكز كما هي — فقط أنماط مشتركة عامة (أزرار، حقول) إن لزم.
