## قواعد التحكم
1. **الأسعار والعقود:** Admin فقط.
2. **التشغيل اليومي (قبول/رفض/مسح/إنهاء):** مركز (App و/أو Web).
3. **هوية العميل ومركبته:** العميل/الشركة ينشئان؛ المركز يستهلك عبر lookup.
4. **إيقاف مركز:** Admin → يجب أن يمنع Login API فوراً.
5. **ما يظهر في التصميم كثابت (أيقونات quick actions):** يمكن أن يكون client-side؛ البيانات ديناميكية عبر API.

## فرق التنفيذ لنفس الوظيفة
| الوظيفة | Center Web | Center App |
|---|---|---|
| تحديث حجز | نموذج Blade + PATCH session | JSON API + بطاقات |
| العمليات | قائمة وحالات | مسح ميداني + كاميرا + صور |
| التقارير | صفحة ويب | تبويب تقارير موبايل |
| الإشعارات | Dropdown + صفحة | قائمة + deep link `center://` |
