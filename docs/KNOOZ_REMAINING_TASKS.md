# المهام المتبقية — تطبيق الشركات Knooz

تاريخ: 2026-11-10

## غير مكتمل بسبب غياب API / نموذج بيانات

| المهمة | السبب |
|---|---|
| إضافة/حذف مركبة من التطبيق | لا يوجد `POST/DELETE /api/company/v1/vehicles`؛ الإدارة تتم من لوحة الويب |
| شحن رصيد المحفظة من التطبيق | لا يوجد endpoint شحن للشركات على مسار الموبايل |
| شريط ميزانية/إنفاق لكل مركبة كما في Figma | لا حقول budget/spend-per-vehicle في API الحالي |
| تنبيهات «وصلت للحد الأقصى» من السيرفر | لا مورد alerts مخصص؛ التطبيق يعرض تنبيهات محلية (رصيد/اشتراك) |
| تصدير سجل المحفظة | زر التصميم دون endpoint تصدير |
| صور العمليات كمعرض مستقل | مسار الشركة للقراءة فقط للعمليات؛ لا upload من تطبيق الشركات |

## تحسينات موصى بها (غير حاجزة للإطلاق الداخلي)

| المهمة | السبب / الملاحظة |
|---|---|
| مطابقة بصرية 100% لأيقونات Figma | استُخدمت أيقونات Material/Theme متوافقة لونياً؛ يمكن استبدالها بـ SVG مستخرجة من Figma |
| اختبارات Flutter widget/integration آلية | نُفّذ analyze + build + اختبار API؛ يحتاج integration_test على CI |
| OTP / التحقق الثنائي | غير موجود في لوحة الشركات الحالية — لم يُختَرع |
| FCM لإشعارات الدفع | البنية تعتمد إشعارات قاعدة البيانات؛ الدفع يحتاج إعداد مشروع Firebase |
| صلاحيات أدوار داخل الشركة أدق من «مستخدم شركة» | إن وُجدت سياسات ويب إضافية يجب عكسها في Resources قبل إخفاء أزرار الموبايل |
| HTTPS و certificate pinning للإنتاج | بيئة التطوير تستخدم HTTP + cleartext |

## ما لم يُختبر بالكامل وأسبابه

| الاختبار | الحالة | السبب |
|---|---|---|
| iOS Simulator | لم يُنفَّذ | بيئة التطوير الحالية Windows + Android emulator |
| إيقاف شركة من Admin ثم التحقق لحظياً من التطبيق المفتوح | جزئي | مغطى باختبار Feature للتوكن؛ لم يُسجَّل سيناريو UI يدوي كامل في هذه الجلسة |
| تعديل صلاحيات دقيقة من Admin وانعكاسها على أزرار التطبيق | معلّق | يعتمد على نموذج صلاحيات أدق غير معرّض بالكامل لـ Company API |

## أولوية مقترحة

1. إن لزم دعم إضافة مركبات/شحن من الموبايل: تصميم API متوافق مع الويب ثم ربط الشاشات.
2. إضافة حقول ميزانية المركبة إن كانت مطلوبة منتجياً.
3. integration_test لتدفق Splash → Login → Home → Logout على CI.
4. تجهيز بيئة إنتاج (HTTPS، متجر، FCM).
